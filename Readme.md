# Collaborative filtering for tool selection in LLM agents

## Цель проекта

В этом проекте мы исследуем, как можно использовать коллаборативную фильтрацию для улучшения качества ранжирования тулзов. В ходе работы мы планируем решить следущие задачи:

- Подготовить данные для работы. Построить матрицу request/tool
- Реализовать метрики и бенчмарк для оценивания
- Реализовать бейзлайн модели
- Реализовать CF-based модели
- Проверить корреляцию метриц ранжирования с успешностью

## Постановка задачи

В качестве пользователя в данной задаче выступает запрос пользователя на естественном языке, а в качестве айтемов - каталог инструментов, с их текстовыми описаниями $\mathcal{T}$. На выходе нужно получить отранжированный список из Top-K тулов, которые попробует применить агент. Использование CF в этой задаче может улучшить успешность выполнение задач.
